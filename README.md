# Myrland client

Downloads for [Myrland](https://myrland.com.mx), a Tibia 8.60 server.

**[Download Myrland.zip](https://github.com/rufogongora/myrland-client/releases/latest/download/Myrland.zip)**, extract it anywhere you can write to (for example Documents) and open `MyrlandLauncher.exe`. The launcher keeps the client up to date by itself.

---
